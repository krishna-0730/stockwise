Stock Update Process

1. Enter Product ID

Enter the ID of the product whose stock quantity needs to be updated.

2. Enter New Quantity

Enter the actual quantity currently available in the inventory.

3. Inventory Updated

The system replaces the existing quantity with the new quantity.

4. Adjustment Recorded

The stock adjustment is automatically stored in Transaction History.
